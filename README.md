☕ Coffee Shop Management System

Developed Using Java

📌 Project Overview

The Coffee Shop Management System is a Java-based desktop application designed to simulate the basic operations of a coffee shop. The system allows users to view coffee items, place orders, manage selected items in a cart, and generate a simple bill. It provides a user-friendly graphical interface similar to a real coffee shop ordering system.

This project is developed for academic and learning purposes to demonstrate Java GUI concepts, event handling, and object-oriented programming.

🚀 Features

User-friendly graphical interface

Menu display with coffee items

Order placement with quantity selection

Cart management (view selected items and total price)

Bill/receipt generation

Multiple pages (Login, Home, Menu, Order, Cart, etc.)

Modular design using separate Java classes

🛠️ Technologies Used

Java

Java Swing / AWT (for GUI)

Object-Oriented Programming (OOP) concepts

📂 Project Structure

Login Page – User login interface

Home Page – Main landing page

Menu Page – Displays available coffee items

Order Page – Allows users to select items and quantities

Cart Page – Shows ordered items and total bill

Navbar – Used for easy navigation between pages

Each page is implemented in a separate Java class for better readability and maintainability.

▶️ How to Run the Project

Open the project in any Java IDE (NetBeans / IntelliJ / Eclipse).

Make sure JDK is installed on your system.

Compile and run the main Java file.

The application will launch as a desktop GUI.

🎯 Purpose of the Project

To practice Java GUI development

To understand event handling in Java

To apply object-oriented programming concepts

To build a mini management system
